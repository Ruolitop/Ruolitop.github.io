第三章 多元线性回归模型

多元线性回归模型的一般形式为：

y=β0+β1x1+β2x2+⋯+βpxp+εy = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p + \varepsilon y=β0​+β1​x1​+β2​x2​+⋯+βp​xp​+ε

多元线性回归模型的基本假定

我们要通过观测的数据对回归模型做参数估计，为了方便，有以下基本假定：

Gauss-Markov 定理

在假定 E(y)=Xβ, D(y)=σ2InE(y)=X\beta,\ D(y)=\sigma^2I_nE(y)=Xβ, D(y)=σ2In​ 时，β\betaβ 任一线性函数 c′βc'\betac′β 的最小方差线性无偏估计 BLUE 为 c′β^c'\hat{\beta}c′β^​，其中 ccc 为 p+1p+1p+1 维常数向量，β^\hat{\beta}β^​ 是 β\betaβ 的 OLSE。

  • 取常数向量ccc 为标准单位向量, G-M定理表明βj^\hat{\beta_j}βj​^​ 是βj\beta_jβj​ 的BLUE
  • 可能存在 y1,y2,…,yny_1, y_2, \dots, y_ny1​,y2​,…,yn​ 的非线性函数，作为 c′βc'\betac′β 的无偏估计，比最小二乘估计 c′β^c'\hat{\beta}c′β^​ 的方差更小。
  • 可能存在 c′βc'\betac′β 的有偏估计量，在某种意义（例如均方误差最小）下比最小二乘估计更好。
  • 在正态假定下，c′β^c'\hat{\beta}c′β^​ 是 c′βc'\betac′β 的最小方差无偏估计。也就是说，既不可能存在 y1,y2,…,yny_1, y_2, \dots, y_ny1​,y2​,…,yn​ 的非线性函数，也不可能存在 y1,y2,…,yny_1, y_2, \dots, y_ny1​,y2​,…,yn​ 的其它线性函数，作为 c′βc'\betac′β 的无偏估计，比最小二乘估计的方差更小。

在0.05的显著性水平下，F检验结果显著，说明回归方程整体高度显著，但是所有的回归系数并不都显著，9个自变量中只有x1，x2，x3，x4, x5, x6的回归系数通过了显著性检验。由于某些自变量对因变量的影响不显著，因而多元回归中并不是包含在回归方程中的自变量越多越好，该问题会在第5章有更详细的讨论。
