即选模型预测的均方误差比全模型预测的方差更小。

性质1和性质2表明，在全模型正确时，用选模型去建立回归模型，参数估计值是有偏估计，用其做预测，预测值也是有偏的。性质3和性质4表明，用选模型去做预测，残差的方差比用全模型去做预测的方差小。性质5说明即使全模型正确，但如果其中有一些自变量对因变量影响很小或回归系数方差过大，则丢掉这些变量之后，用选模型去预测可以提高预测的精度。

从上述性质可以看到，一个好的回归模型，并不是考虑的自变量越多越好。在建立回归模型时，选择自变量的基本指导思想是“少而精”。丢掉了一些对因变量 yyy 有影响的自变量后，所付出的代价是估计量产生了有偏性。然而，尽管估计量是有偏的，但预测偏差的方差会下降。另外，如果保留下来的自变量有些对因变量无关紧要，那么，方程中包括这些变量会导致参数估计和预测的有偏性和精度降低。

自变量选择的几个准则

SSEp+1≤SSEp\text{SSE}_{p+1} \leq \text{SSE}_p SSEp+1​≤SSEp​

准则1 自由度调整复决定系数 Ra2R_a^2Ra2​ 达到最大。

Ra2=1−n−1n−p−1(1−R2)R_a^2 = 1 - \frac{n-1}{n-p-1}(1-R^2) Ra2​=1−n−p−1n−1​(1−R2)

显然有 Ra2≤R2R_a^2 \leq R^2Ra2​≤R2，Ra2R_a^2Ra2​ 随着自变量的增加并不一定增大，尽管 1−R21-R^21−R2 随着变量的增加而减少，但由于其前面的系数 (n−1)/(n−p−1)(n-1)/(n-p-1)(n−1)/(n−p−1) 起折扣作用。从拟合角度追求最优，则所有回归子集中 Ra2R_a^2Ra2​ 最大者对应的回归方程就是最优方程。

从另外一个角度考虑回归的拟合效果，回归误差项方差 σ2\sigma^2σ2 的无偏估计为：

Ra2=1−n−1SSTσ^2R_a^2 = 1 - \frac{n-1}{\text{SST}}\hat{\sigma}^2 Ra2​=1−SSTn−1​σ^2

准则2 赤池信息量AIC达到最小。

AIC准则是日本统计学家赤池(Akaike)1974年根据极大似然估计原理提出的一种较为一般的模型选择准则，人们称它为Akaike信息量准则 (Akaike Information Criterion,简记为AIC)。AIC准则既可用来作回归方程自变量的选择，又可用于时间序列分析中自回归模型的定阶上。

设回归模型的似然函数为 L(θ,x)L(\theta,x)L(θ,x)，θ\thetaθ 的维数为 ppp，xxx 为随机样本（在回归分析中样本为 y=(y1,y2,…,yn)′\boldsymbol{y}=(y_1,y_2,\dots,y_n)'y=(y1​,y2​,…,yn​)′），则AIC定义为：

AIC=−2ln⁡L(θ^L,x)+2p\text{AIC} = -2\ln L(\hat{\theta}_L,x) + 2p AIC=−2lnL(θ^L​,x)+2p

式中，θ^L\hat{\theta}_Lθ^L​ 为 θ\thetaθ 的最大似然估计；ppp 为未知参数的个数。由于似然函数越大的估计量越好，因而在回归模型中使AIC达到最小的模型是最优模型。

下面讨论把AIC准则用于回归模型的选择。假定回归模型的随机误差项 ε\varepsilonε 服从正态分布，即 ε∼N(0,σ2)\varepsilon \sim N(0,\sigma^2)ε∼N(0,σ2)。

将 σ^L2=1nSSE\hat{\sigma}_L^2 = \frac{1}{n}\text{SSE}σ^L2​=n1​SSE 代入得：

逐步回归

自变量的所有可能子集构成2m−12m-12m−1个回归方程，当可供选择的自变量不太多时，用前边的方法可以求出一切可能的回归方程，然后用几个选元准则去挑选最优的方程，但是当自变量的个数较多时，要求出所有可能的回归方程是非常困难的。为此，人们提出了一些较为简便、实用、快速的选择最优方程的方法。人们所给出的方法各有优缺点，至今还没有绝对最优的方法，目前常用的方法有前进法、后退法、逐步回归法，而逐步回归法最受推崇。

前进法

  1. 初始模型：不含任何变量，只有常数项

  2. 对于未选入的变量，分别加入到模型中并计算AIC

  3. 选择使AIC最小的变量加入到模型中，重复2和3

后退法

  1. 初始模型：全模型

  2. 对于选入的变量，分别剔除出模型并计算AIC

  3. 选出最小的AIC值并确定应该剔除的变量，重复23

  4. 直至回归方程中剩余的p个变量中再任意剔除一个，AIC值都会增加

逐步回归法

前进法和后退法显然都有明显的不足。使用前进法变量一旦被引入，就没有机会将其剔除；类似地，后退法中一旦某个自变量被剔除，它就再也没有机会重新进入回归方程。逐步回归会把两者的优点结合起来，并克服它们的不足。

  1. 给定了包含p个变量的初始模型后，计算初始模型的 AIC 值，
  2. 分别剔除p个变量中的任一个和添加剩余m−p个变量中的任一变量后, 计算 AIC 值
  3. 选择最小的 AIC 值决定是否添加新变量或剔除已存在初始模型中的变量，重复23
  4. 直至既不添加新变量也不剔除模型中已有的变量时所对应的 AIC 值最小
