多重共线性

发表于2026-05-03|更新于2026-09-23|回归分析多重共线性
|总字数:3.8k|阅读时长:16分钟|浏览量:

如果存在不全为 0 的 p+1p+1p+1 个数 c0,c1,…,cpc_0, c_1, \dots, c_pc0​,c1​,…,cp​，使得

c0+c1xi1+c2xi2+⋯+cpxip=0,i=1,2,…,n(6.1)c_0 + c_1 x_{i1} + c_2 x_{i2} + \dots + c_p x_{ip} = 0,\quad i = 1,2,\dots,n \tag{6.1} c0​+c1​xi1​+c2​xi2​+⋯+cp​xip​=0,i=1,2,…,n(6.1)

则称自变量 x1,x2,…,xpx_1, x_2, \dots, x_px1​,x2​,…,xp​ 之间存在着完全多重共线性。更常见的是（6.1）式近似成立的情况：

c0+c1xi1+c2xi2+⋯+cpxip≈0,i=1,2,…,n(6.2)c_0 + c_1 x_{i1} + c_2 x_{i2} + \dots + c_p x_{ip} \approx 0,\quad i = 1,2,\dots,n \tag{6.2} c0​+c1​xi1​+c2​xi2​+⋯+cp​xip​≈0,i=1,2,…,n(6.2)

则称自变量 x1,…,xpx_1, \dots, x_px1​,…,xp​ 之间存在着多重共线性（Multi-collinearity），也称为复共线性。

当我们所研究的经济问题涉及到时间序列资料时，由于经济变量随时间往往存在共同的变化趋势，它们之间就容易出现共线性。

例如，我们要研究我国居民消费状况，影响居民消费的因素很多，一般有职工平均工资、农民平均收入、银行利率、全国零售物价指数、国债利率、货币发行量、储蓄额、前期消费额等，这些因素显然既对居民消费产生重要影响，它们之间又有着很强的相关性。

许多利用截面数据建立回归方程的问题常常也存在自变量高度相关的情形。

例如，我们以企业的截面数据为样本估计生产函数，由于投入要素资本 KKK，劳动力投入 LLL，科技投入 SSS，能源供应 EEE 等都与企业的生产规模有关，所以它们之间存在较强的相关性。

y=β0+β1x1+β2x2+⋯+βpxp+εy = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p + \varepsilon y=β0​+β1​x1​+β2​x2​+⋯+βp​xp​+ε

存在完全的多重共线性，即对设计矩阵 XXX 的列向量存在不全为零的一组数 c0,c1,…,cpc_0, c_1, \dots, c_pc0​,c1​,…,cp​，使得

设计矩阵 XXX 的秩 rank(X)<p+1\text{rank}(X) < p+1rank(X)<p+1，此时 ∣X′X∣=0|X'X| = 0∣X′X∣=0，正规方程组的解不唯一，(X′X)−1(X'X)^{-1}(X′X)−1 不存在，回归参数的最小二乘估计表达式 β^=(X′X)−1X′y\hat{\beta} = (X'X)^{-1}X'yβ^​=(X′X)−1X′y 不成立。

对非完全共线性，存在不全为零的一组数 c0,c1,…,cpc_0, c_1, \dots, c_pc0​,c1​,…,cp​，使得

c0+c1xi1+c2xi2+⋯+cpxip≈0,i=1,2,…,nc_0 + c_1 x_{i1} + c_2 x_{i2} + \dots + c_p x_{ip} \approx 0,\quad i = 1,2,\dots,n c0​+c1​xi1​+c2​xi2​+⋯+cp​xip​≈0,i=1,2,…,n

多重共线性的诊断

方差扩大因子法

对自变量做中心标准化，则 X∗′X∗/(n−1)=(rij)X^{*'}X^{*}/(n-1)=(r_{ij})X∗′X∗/(n−1)=(rij​) 为自变量的相关阵。记

C=(cij)=(n−1)(X∗′X∗)−1(6.5)C=(c_{ij})=(n-1)(X^{*'}X^{*})^{-1} \tag{6.5} C=(cij​)=(n−1)(X∗′X∗)−1(6.5)

称其主对角线元素 VIFj=cjjVIF_j = c_{jj}VIFj​=cjj​ 为自变量 xjx_jxj​ 的方差扩大因子（Variance Inflation Factor，简记为VIF），

var⁡(β^j)=cjjσ2/Ljj,j=1,…,p(6.6)\operatorname{var}(\hat{\beta}_j)=c_{jj}\sigma^2/L_{jj},\quad j=1,\dots,p \tag{6.6} var(β^​j​)=cjj​σ2/Ljj​,j=1,…,p(6.6)

其中 LjjL_{jj}Ljj​ 是 xjx_jxj​ 的离差平方和，由（6.6）式可知用 cjjc_{jj}cjj​ 作为衡量自变量 xjx_jxj​ 的方差扩大程度的因子是恰如其分的。记 Rj2R_j^2Rj2​ 为以 xjx_jxj​ 作因变量对其余 p−1p-1p−1 个自变量进行回归得到的复决定系数，可以证明

cjj=11−Rj2(6.7)c_{jj} = \frac{1}{1-R_j^2} \tag{6.7} cjj​=1−Rj2​1​(6.7)

式(6.7)也可以作为方差扩大因子 VIFjVIF_jVIFj​ 的定义，由此式可知 VIFj≥1VIF_j \ge 1VIFj​≥1。经验表明，当 VIFj≥10VIF_j \ge 10VIFj​≥10 时，就说明自变量 xjx_jxj​ 与其余自变量之间有严重的多重共线性，且这种多重共线性可能会过度地影响最小二乘估计值。

还可用 ppp 个自变量所对应的方差扩大因子的平均数来度量多重共线性。当

特征根判定法

根据矩阵行列式的性质，矩阵的行列式等于其特征根的连乘积。因而，当行列式 ∣X′X∣≈0|X'X| \approx 0∣X′X∣≈0 时，矩阵 X′XX'XX′X 至少有一个特征根近似为零。反之可以证明，当矩阵 X′XX'XX′X 至少有一个特征根近似为零时，XXX 的列向量间必存在复共线性。

证明如下：

记 X=(X0,X1,…,Xp)X = (X_0, X_1, \dots, X_p)X=(X0​,X1​,…,Xp​)，其中 XiX_iXi​ 为 XXX 的列向量，X0=(1,1,…,1)′X_0 = (1,1,\dots,1)'X0​=(1,1,…,1)′ 是元素全为1的 nnn 维列向量。λ\lambdaλ 是矩阵 X′XX'XX′X 的一个近似为零的特征根，λ≈0\lambda \approx 0λ≈0，c=(c0,c1,…,cp)′c = (c_0, c_1, \dots, c_p)'c=(c0​,c1​,…,cp​)′ 是对应于特征根 λ\lambdaλ 的单位特征向量，则

X′Xc=λc≈0X'Xc = \lambda c \approx 0 X′Xc=λc≈0

上式两边左乘 c′c'c′，得 c′X′Xc≈0c'X'Xc \approx 0c′X′Xc≈0。
从而有 Xc≈0Xc \approx 0Xc≈0，即

c0X0+c1X1+⋯+cpXp≈0c_0X_0 + c_1X_1 + \dots + c_pX_p \approx 0 c0​X0​+c1​X1​+⋯+cp​Xp​≈0

写成分量形式即为

c0+c1xi1+⋯+cpxip≈0,i=1,2,…,nc_0 + c_1x_{i1} + \dots + c_px_{ip} \approx 0,\quad i=1,2,\dots,n c0​+c1​xi1​+⋯+cp​xip​≈0,i=1,2,…,n

这正是（6.2）式定义的多重共线性关系。

如果矩阵 X′XX'XX′X 有多个特征根近似为零，在上面的证明中，取每个特征根的特征向量为标准化正交向量，即可证明：X′XX'XX′X 有多少个特征根接近于零，设计矩阵 XXX 就有多少个多重共线性关系，并且这些多重共线性关系的系数向量就等于接近于零的那些特征根对应的特征向量。

条件数

特征根分析表明，当矩阵 X′XX'XX′X 有一个特征根近似为零时，设计矩阵 XXX 的列向量间必存在复共线性。那么特征根近似为零的标准如何确定呢？可以用下面介绍的条件数确定。记 X′XX'XX′X 的最大和最小特征根分别为 λmax⁡\lambda_{\max}λmax​ 和 λmin⁡\lambda_{\min}λmin​，称

k(X′X)=λmax⁡λmin⁡k(X'X) = \frac{\lambda_{\max}}{\lambda_{\min}} k(X′X)=λmin​λmax​​

为矩阵 X′XX'XX′X 的条件数（Condition Index）。用条件数判断多重共线性的准则：

  • k<100k < 100k<100 时，设计矩阵 XXX 多重共线性程度较小；
  • 100≤k≤1000100 \le k \le 1000100≤k≤1000 时，认为 XXX 存在较强的多重共线性；
  • 当 k>1000k > 1000k>1000 时，认为存在严重的多重共线性。

当X′XX'XX′X 所有特征根都比较小时，虽然条件数不大，但多重共线性却仍可能存在

直观判定法

1.当增加或剔除一个自变量，或者改变一个观测值时，回归系数的估计值发生较大变化。
2.从定性分析角度看来，一些重要的自变量在回归方程中没有通过显著性检验。
3.有些自变量的回归系数所带正负号与定性分析结果违背。
4.自变量的相关矩阵中，自变量间的相关系数较大。
5.一些重要的自变量的回归系数的标准误差较大。

消除多重共线性的方法

剔除不重要的解释变量

​ 在剔除自变量时，可以将回归系数的显著性检验、方差扩大因子VIF以及自变量的经济含义结合起来考虑，以引进或剔除变量。

增大样本容量

例如

var⁡(β^1)=σ2(1−r122)L11,var⁡(β^2)=σ2(1−r122)L22\operatorname{var}(\hat{\beta}_1) = \frac{\sigma^2}{(1-r_{12}^2)L_{11}},\quad \operatorname{var}(\hat{\beta}_2) = \frac{\sigma^2}{(1-r_{12}^2)L_{22}} var(β^​1​)=(1−r122​)L11​σ2​,var(β^​2​)=(1−r122​)L22​σ2​

可以看到，在 r12r_{12}r12​ 固定不变，当样本容量 nnn 增大时，L11L_{11}L11​ 和 L22L_{22}L22​ 都会增大，两个回归系数的估计方差均可减小，从而减弱多重共线性对回归方程的影响。

回归系数的有偏估计

消除多重共线性对回归模型的影响是近40年来统计学家们关注的热点课题之一，除以上方法被人们应用外，统计学家还致力于改进古典的最小二乘法，提出以采用有偏估计为代价来提高估计量稳定性的方法，如：

  • 岭回归法
  • 主成分回归法
  • 偏最小二乘法等

当解释变量之间的简单相关系数很大时，可以断定自变量间存在着严重的多重共线性；但是一个回归方程存在严重的多重共线性时，解释变量之间的简单相关系数不一定很大。例如假定3个自变量之间有完全确定的关系
