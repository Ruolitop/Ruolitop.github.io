违背基本假设的几种情况

回顾多元线性回归模型中的几个基本假设：

  1. 解释变量 x1,x2,…,xpx_1,x_2,\dots,x_px1​,x2​,…,xp​ 是确定性变量，并且 r(X)=p+1<nr(X) = p+1 < nr(X)=p+1<n
  2. 满足 Gauss-Markov 条件：E(εi)=0, Cov(εi,εj)=δijσ2, ∀i,j=1,2,…,nE(\varepsilon_i)=0,\ \mathrm{Cov}(\varepsilon_i,\varepsilon_j) = \delta_{ij}\sigma^2,\ \forall i,j=1,2,\dots,nE(εi​)=0, Cov(εi​,εj​)=δij​σ2, ∀i,j=1,2,…,n
  3. 正态分布假设：εi∼iidN(0,σ2)\varepsilon_i \stackrel{\mathrm{iid}}{\sim} N(0,\sigma^2)εi​∼iidN(0,σ2)（等价于 ε∼N(0,σ2In)\varepsilon \sim N(0,\sigma^2 I_n)ε∼N(0,σ2In​)）

异方差性问题及其处理

例:居民收入与消费水平有着密切的关系。用 xix_ixi​ 表示第 iii 户的收入量，yiy_iyi​ 表示第 iii 户的消费额，一个简单的消费模型为：

yi=β0+β1xi+εi,i=1,2,…,n y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \quad i=1,2,\dots,n yi​=β0​+β1​xi​+εi​,i=1,2,…,n

低收入的家庭购买差异性比较小，高收入的家庭购买行为差异就很大，导致消费模型的随机项 εi\varepsilon_iεi​ 具有不同的方差。

当存在异方差时，普通最小二乘估计存在以下问题：

  1. 参数估计值虽是无偏的，但不是最小方差线性无偏估计；
  2. 参数的显著性检验失效；
  3. 回归方程的应用效果极不理想。

自相关性问题及其处理

如果一个回归模型的随机误差项

cov⁡(εi,εj)≠0,i,j=1,2,…,n\operatorname{cov}(\varepsilon_i, \varepsilon_j) \neq 0, \quad i, j = 1, 2, \ldots, n cov(εi​,εj​)​=0,i,j=1,2,…,n

则称随机误差项之间存在着自相关现象。

这里的自相关现象不是指两个或两个以上的变量之间的相关，而是指一个变量前后期数值之间存在的相关关系。

自相关性产生的原因

  1. 遗漏关键变量时会产生序列的自相关性。
  2. 经济变量的滞后性会给序列带来自相关性。
  3. 采用错误的回归函数形式也可能引起自相关性。
  4. **蛛网现象（Cobweb phenomenon）**可能带来序列的自相关性。
  5. 因对数据加工整理而导致误差项之间产生自相关性。

自相关性带来的影响

  1. 参数的估计值不再具有最小方差线性无偏性。
  2. 均方误差 MSE 可能严重低估误差项的方差。
  3. 容易导致对 t 值评价过高，常用的 F 检验和 t 检验失效。
  4. 当存在序列相关时，(\beta) 仍然是 (\beta) 的无偏估计量，但在任一特定的样本中，可能严重歪曲 (\beta) 的真实情况，即最小二乘估计量对抽样波动变得非常敏感。
  5. 如果不加处理地运用普通最小二乘法估计模型参数，用此模型进行预测和结构分析将会带来较大的方差甚至错误的解释。

DW检验的缺点和局限性

  • DW检验有一个不能确定的区域，一旦DW值落在这个区域，就无法判断，这时只有增大样本容量或选取其他方法。
  • DW统计量的上、下界表要求n＞15，这是因为样本如果再小利用残差就很难对自相关的存在性做出比较正确的诊断。
  • DW检验不适应随机项具有高阶序列相关的检验。

差分法

一阶差分法通常适用于原模型存在较高程度的一阶自相关的情况。

在式 yt−ρyt−1=(β0−ρβ0)+β1(xt−ρxt−1)+(εt−ρεt−1)y_t - \rho y_{t-1} = (\beta_0 - \rho\beta_0) + \beta_1(x_t - \rho x_{t-1}) + (\varepsilon_t - \rho\varepsilon_{t-1})yt​−ρyt−1​=(β0​−ρβ0​)+β1​(xt​−ρxt−1​)+(εt​−ρεt−1​) 中，当 ρ=1\rho=1ρ=1 时，得：

yt−yt−1=β1(xt−xt−1)+εt−εt−1y_t - y_{t-1} = \beta_1(x_t - x_{t-1}) + \varepsilon_t - \varepsilon_{t-1} yt​−yt−1​=β1​(xt​−xt−1​)+εt​−εt−1​

以 Δyt=yt−yt−1\Delta y_t = y_t - y_{t-1}Δyt​=yt​−yt−1​，Δxt=xt−xt−1\Delta x_t = x_t - x_{t-1}Δxt​=xt​−xt−1​ 代之，得：

Δyt=β1Δxt+ut\Delta y_t = \beta_1 \Delta x_t + u_t Δyt​=β1​Δxt​+ut​

上式是不带有常数项的回归方程，则有：

β^1=∑t=2nΔytΔxt∑t=2nΔxt2\hat{\beta}_1 = \frac{\sum_{t=2}^n \Delta y_t \Delta x_t}{\sum_{t=2}^n \Delta x_t^2} β^​1​=∑t=2n​Δxt2​∑t=2n​Δyt​Δxt​​

一阶差分法的应用条件是自相关系数 ρ=1\rho=1ρ=1，在实际应用中，ρ\rhoρ 接近1时我们就采用差分法而不用迭代法，这有两个原因。

第一，迭代法需要用样本估计自相关系数 ρ\rhoρ，对 ρ\rhoρ 的估计误差会影响迭代法的使用效率；

第二，差分法比迭代法简单，人们在建立时序数据的回归模型时，更习惯于用差分法。

异常值与强影响点

异常值分为两种情况：一种是关于因变量 yyy 异常，另一种是关于自变量 xxx 异常。

关于因变量 yyy 异常

在残差分析中，认为超过 ±3σ^\pm 3\hat{\sigma}±3σ^ 的残差为异常值。

  • 标准化残差：

ZREi=eiσ^\text{ZRE}_i = \frac{e_i}{\hat{\sigma}} ZREi​=σ^ei​​

  • 学生化残差：

SREi=eiσ^1−hii\text{SRE}_i = \frac{e_i}{\hat{\sigma}\sqrt{1-h_{ii}}} SREi​=σ^1−hii​​ei​​

其中，hiih_{ii}hii​ 是帽子矩阵 H=X(X′X)−1X′H = X(X'X)^{-1}X'H=X(X′X)−1X′ 的主对角线元素。

当数据中存在关于 yyy 的异常观测值时，异常值会把回归线拉向自身，使异常值本身的残差减少，而其余观测值的残差增大，这时回归残差的标准差 σ^\hat{\sigma}σ^ 也会增大，因而用“3σ3\sigma3σ”准则不能正确分辨出异常值。

解决这个问题的方法是改用删除残差。

删除残差的构造思想是：在计算第 iii 个观测值的残差时，用删除掉第 iii 个观测值的其余 n−1n-1n−1 个观测值拟合回归方程，计算出第 iii 个观测值的删除拟合值 y^(i)\hat{y}_{(i)}y^​(i)​，它与第iii个值无关，定义第 iii 个观测值的删除残差为：

e(i)=yi−y^(i)e_{(i)} = y_i - \hat{y}_{(i)} e(i)​=yi​−y^​(i)​

删除残差 e(i)e_{(i)}e(i)​ 相比普通残差更能如实反映第 iii 个观测值的异常性，可以证明：

e(i)=ei1−hiie_{(i)} = \frac{e_i}{1-h_{ii}} e(i)​=1−hii​ei​​

进一步可以给出第 iii 个观测值的删除学生化残差，记为 SRE(i)\text{SRE}_{(i)}SRE(i)​：

SRE(i)=SREi(n−p−1n−p−2−SREi2n−p−2)−12\text{SRE}_{(i)} = \text{SRE}_i \left( \frac{n-p-1}{n-p-2} - \frac{\text{SRE}_i^2}{n-p-2} \right)^{-\frac{1}{2}} SRE(i)​=SREi​(n−p−2n−p−1​−n−p−2SREi2​​)−21​

在 D(ei)=(1−hii)σ2D(e_i)=(1-h_{ii})\sigma^2D(ei​)=(1−hii​)σ2 中，hiih_{ii}hii​ 为帽子矩阵中主对角线的第 iii 个元素，它是调节 eie_iei​ 方差大小的杠杆，因而称 hiih_{ii}hii​ 为第 iii 个观测值的杠杆值。较大的杠杆值的残差偏小，这是因为杠杆值大的观测点远离样本中心，能够把回归方程拉向自身，因而把杠杆值大的样本点称为强影响点。

异常值处理

消除异常值
异常值原因 异常值消除方法
1. 数据登记误差，存在抄写或录入的错误 重新核实数据
2. 数据测量误差 重新测量数据
3. 数据随机误差 删除或重新观测异常值数据
4. 缺少重要自变量 增加必要的自变量
5. 缺少观测数据 增加观测数据，适当扩大自变量取值范围
6. 存在异方差 采用加权线性回归
7. 模型选用错误，线性模型不适用 改用非线性回归模型

对异常观测值，不能总是简单地剔除了事，有时异常观测值是正确的，它说明了回归模型为什么失败。

如果一个异常值数据是准确的，但是找不到对它的合理解释，那么与剔除这个观测值相比，一种更稳健的方法是抑制它的影响。最小绝对离差和法是一种稳健估计方法，它具有对异常值和不合适模型不敏感的性质。
